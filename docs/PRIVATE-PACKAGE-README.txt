86Box ThinkPad 700 / 700C private Windows x64 package
====================================================

Double-click Start-ThinkPad-700.bat to start the configured machine.
Ctrl+End releases the mouse. Ctrl+Alt+Page Up toggles full screen.

This private package includes locally supplied IBM firmware, a Reference
Diskette, diagnostics (when available), and a working system disk. Do not
upload or redistribute it. The public GitHub repository intentionally contains
source code only.
